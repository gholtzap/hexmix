Integration routes

Three proven ways to connect.

01
Real-time

Direct API integration

Continuous, bidirectional data exchange between Nuvexa and your systems, built for high volumes, for example via SAP OData or IDoc.

02
File-based

Managed file transfer

Automated exchange via SFTP, using the files and formats your systems already produce. No development required.

03
Scheduled

Scheduled API sync

Nuvexa pulls articles, customers and contacts from your system’s API at fixed intervals. Configured in the settings, not coded.
